# СамМари — архитектура v1 (MVP)

## Этап 1 (до запуска)
1. Android-приложение (Flutter) → RuStore
2. Лендинг sum-mary.ru
3. Программа для Windows (тот же Flutter-код + захват звука системы)

После запуска: iPhone, macOS, часы, бот для Zoom/Meet/Телемост, Whisper на GPU.

## Принятые решения
| Что | Решение | Почему |
|---|---|---|
| Распознавание речи | GigaAM-v3 (Сбер, MIT) на CPU | лучший русский среди бесплатных, не нужен GPU; Whisper — позже |
| Разделение спикеров | sherpa-onnx (pyannote segmentation 3.0 + wespeaker), без токенов | работает на CPU; на Windows — ещё и отдельные каналы «микрофон = Я / звук ПК = остальные» |
| Резюме, задачи, чат | DeepSeek API напрямую (`deepseek-chat`) | лучшее качество/цена (~1 ₽ за час записи). Переключаемо на DeepSeek в Yandex AI Studio (данные в РФ) |
| База, вход, файлы | Supabase self-hosted на VPS Beget | данные в РФ (152-ФЗ), Postgres + Auth + Storage + Realtime |
| Вход | Email + одноразовый код | бесплатно, встроено в Supabase |
| Оплата | Подписка RuStore Billing | Android в RuStore |
| Аудио | хранится только на устройстве; на сервер — временно, удаляется сразу после обработки | экономия места |

## Схема работы
```
[Телефон / ПК]
  запись (AAC 32 кбит/с моно, ~14 МБ/час) ──upload──▶ Supabase Storage (bucket audio, временно)
  recordings.status = 'queued'
                                   │
[Worker на VPS] ◀──── берёт задание (SELECT … FOR UPDATE SKIP LOCKED)
  1. ffmpeg → wav 16 кГц
  2. silero VAD + GigaAM-v3 → текст с таймкодами
  3. sherpa-onnx → спикеры
  4. DeepSeek → JSON: название, резюме, решения, задачи, ответственные, открытые вопросы, исправления терминов
  5. исправления терминов применяются к транскрипту
  6. запись в БД, удаление аудио из Storage, status = 'ready'
                                   │
[Приложение] ◀── Supabase Realtime: статус и результаты обновляются сами
[Чат с Мари] ──▶ api.sum-mary.ru/chat (FastAPI, проверка JWT Supabase) ──▶ DeepSeek
```

## Домены
- `sum-mary.ru` — лендинг (+ /privacy, /terms)
- `db.sum-mary.ru` — Supabase (Kong API)
- `api.sum-mary.ru` — наш API (чат с Мари, вебхуки оплаты)

## Сервер (VPS Beget)
Минимум 4 vCPU / 8 ГБ RAM / 80 ГБ NVMe: Supabase ~3 ГБ, worker ~3 ГБ.
Скорость на 1 час записи (по тесту на i7-12700T): распознавание ~8 мин + спикеры ~9 мин. На 4 vCPU — примерно в 2 раза дольше; задания идут в очереди. Масштабирование — второй worker на отдельном VPS.

## Функции v1 (по образцу Wave)
- Запись с микрофона (фоном, с уведомлением), пауза/продолжить
- Импорт аудиофайлов и записей звонков (встроенный диктофон звонков Android)
- Экран обработки: загрузка → расшифровка → резюме
- Карточка записи: Резюме / Транскрипт (спикеры, таймкоды) / Задачи; плеер; переименование спикеров; чат с Мари по записи
- Общий список задач (открытые/выполненные)
- Папки, избранное, поиск
- Пользовательский словарь терминов (передаётся в DeepSeek)
- Экспорт: поделиться текстом резюме/транскрипта
- Подписка: бесплатно 30 мин/мес, платный тариф — безлимит (RuStore)
- Windows: запись «микрофон + звук системы» (две дорожки)

## Юридическое (до публичного запуска)
- ИП/ООО, уведомление РКН об обработке ПДн
- Уведомление РКН о трансграничной передаче (DeepSeek, Китай — страна с «адекватной защитой»)
- Политика конфиденциальности и пользовательское соглашение на сайте и в приложении
- Предупреждение о записи разговоров (собеседника нужно уведомить)

## v2 (октябрь 2026) — дизайн «Ночной эфир»
- Тема: `lib/theme.dart` — палитра `Sm` (ThemeExtension) в светлой и тёмной версиях, доступ `context.sm`; шрифты Unbounded (заголовки, `display()`) и Manrope (текст) через google_fonts; выбор темы Авто/Светлая/Тёмная в профиле (`ThemeController`, shared_preferences).
- Шар Мари: `lib/widgets/mari_orb.dart` — «дышит» в покое, пульсирует от громкости при записи.
- Режимы записи: `lib/modes.dart` (Урок, Лекция, Семинар, Встреча, Звонок, Собеседование, Продажи, Репетитор) → колонка `recordings.mode`.
- Метки во время записи: «Фото доски», «Важно!», «Не понял» → `recordings.marks` (jsonb: type, t — секунда записи, path — фото на устройстве).
- Главная «Сегодня»: приветствие, «Спросить Мари», быстрые режимы, ближайшие задачи, недавние записи. Нижняя панель-«стекло» с шаром записи (долгое нажатие — выбор режима).
- Миграция: `supabase/migrations/0002_v2_modes.sql` (применена 07.10.2026).
